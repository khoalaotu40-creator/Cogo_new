# Backend Notes for Location Suggestions

The location search functionality in the `FindRideForm` component needs to be connected to a backend service.

1. **Current Location (Vị trí hiện tại):**
   - The frontend can use `navigator.geolocation` to get coordinates (lat, lng).
   - The backend should provide a reverse geocoding API to convert coordinates into a readable address.
   - Endpoint example: `GET /api/locations/reverse?lat=...&lng=...`

2. **Autocomplete Suggestions (Gợi ý tìm kiếm):**
   - When the user types in the input field, the frontend should debounce the input and send a query to the backend.
   - The backend should integrate with a service like Google Maps Places API or OpenStreetMap Nominatim to return location suggestions.
   - Endpoint example: `GET /api/locations/suggest?q=query`
   - Response should include a list of locations with `id`, `name`, `address`, `lat`, and `lng`.
